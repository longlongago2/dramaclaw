# Stickman theme preview sources

These static PNG previews are extracted from the corresponding demonstration GIFs
in `kaomei/stickman-video-director`, commit
`61064554e6227f48ff717a35d43e22fa69c2c031`.
See `sources.json` for exact source paths, frame indices and SHA-256 checksums.
The upstream MIT license and copyright notice are retained in `LICENSE`.
Visible attribution, captions and artwork in the source frames are preserved.

`2b.png` is the user's supplied Style 2B frame, copied unchanged from
`../stickman.png`. The latter remains the default preset cover.

The style preview API serves these images. They are not generation outputs or
model reference images, and do not belong in `frontend/public/style-gallery/`.
