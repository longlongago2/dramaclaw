# 项目显示名称与文件夹名称

项目显示名称支持中文及其他语言，最多 64 个 Unicode 码点。创建时自动去除首尾空白，
统一为 NFC，不允许空名称、换行或控制字符。名称中的空格、标点不参与目录生成。

项目有三个独立字段：

| 字段 | 用途 | 示例 |
| --- | --- | --- |
| `id` | 路由、权限、任务使用的稳定身份 | 26 位 ULID |
| `name` | 固定内部名称及文件夹名称 | `p_<ULID>` |
| `display_name` | 用户可编辑的显示名称 | `火柴人` |

新界面只需输入显示名称。创建接口由注册表生成 `p_<项目ID>` 作为内部名称，
三类存储目录仍按 `<root>/<owner>/<name>` 组织。列表、搜索、名称排序、项目切换器、
分享和操作提示显示 `display_name`。同一属主的显示名称不能重名；归档、回收站项目
继续占用名称，彻底删除后释放。

项目卡片和列表的操作菜单提供“重命名”。项目管理员或所有者可修改显示名称，
项目 ID、内部名称、目录和已有文件保持原样。

## API 兼容

新客户端创建：

```json
{"display_name": "火柴人"}
```

旧客户端仍可提交 `{"name": "legacy_project"}`。`name` 继续遵循原有 ASCII 规则，
对应目录名保持原样，默认显示名称等于 `name`。同时提交两者时，`name` 指定内部名称，
`display_name` 指定显示名称。

创建响应，以及项目列表、摘要、详情响应，保留 `name` 并增加 `display_name`。
客户端读取旧响应时应回退到 `name`，但路由和缓存身份继续使用项目 ID。

修改名称使用 `PATCH /api/v1/projects/{id}/display-name`：

```json
{"display_name": "火柴人 第二部"}
```

重名返回 409，输入不合法返回 422，权限不足返回 403。改名只更新项目注册表，
不写入本地 `project_config.json`，因此无需访问项目所在节点的文件系统。

## 存量数据与注册适配器

CE 注册表在首次连接时自动执行第 2 版增量迁移：增加 `display_name`，将旧项目名称
补为显示名称，并建立同属主下有效显示名称的唯一索引。重复启动可安全重复检查，
不修改旧项目 ID、路径或文件。索引对空显示名称回退为 `name`，兼容旧代码写入的记录。

外置 EE 注册适配器须同步扩展 `ProjectRecord.display_name`，支持创建时省略 `name`
并生成内部名称，以及实现 `update_project_display_name` 和相应的数据库约束。
旧适配器仍可处理旧格式创建和读取；请求新功能时返回 501，提示升级适配器。
