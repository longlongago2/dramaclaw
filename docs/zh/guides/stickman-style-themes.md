# 火柴人画风主题

日期：2026-10-14。状态：本地实现，真实模型连续视频效果尚待验收。

## 产品行为

保留一个 `stickman` 预设，增加可选主题：

| 值 | 显示名 | 视觉规则 |
| --- | --- | --- |
| `null` | 跟随预设 | 白底黑线，兼容首版和旧项目 |
| `classic` | 基础黑白 | 白底、黑线、空心圆头、简化表情 |
| `modern` | 现代潮酷 | 对应上游彩色故事方向：二维火柴人搭配彩色环境与电影光影 |
| `prehistoric` | 史前手绘 | 白色填充头部、夸张简洁表情、粗手绘线条、土色和轻纸张纹理 |

三个主方向下增加具体画风级联：基础黑白包含 `1a` 白底黑线和 `1b` 黑底白线；现代潮酷包含 `2a` 极简科技和 `2b` 彩色故事；史前手绘使用 `3`，不显示无意义的第二级。仍然只有一个火柴人预设。

保存时使用具体画风 ID。旧的 `classic`、`modern`、`prehistoric` 分别兼容解释为 `1a`、`2b`、`3`，无需强制迁移。选择主方向时默认基础黑白使用 `1a`，现代使用 `2b`，史前使用 `3`。未选择仍保留默认白底黑线生成规则。

选择具体画风后，详情预览立即请求对应的静态图，不需要先保存项目。预览接口通过 `theme` 查询参数返回 `styles/presets/stickman-previews/<variant>.png`；仅允许预设声明的主题，拒绝其他预设的无效主题及路径输入。恢复“跟随预设”显示原来的 `stickman.png`。

`1a`、`1b`、`2a`、`3` 预览取自上游 README 中各自的演示 GIF 静态帧；`2b` 直接复用用户指定的原图，与默认封面字节一致。上游提交、素材路径、帧号及校验和记录在 `stickman-previews/sources.json`，保留上游 MIT 许可与可见署名。所有资源均在后端预设目录，不新增前端画布资源。

其他预设不声明主题能力时不显示控件。界面使用项目共用的 Base UI / shadcn Select，支持键盘选择与恢复默认。主线选择后点击“应用到项目”保存；当前默认预设也可以更改主题。

主题只影响后续生成，不自动生成或覆盖已有素材。现代红帽黄衣、史前兽皮洞穴作为内容未指定时的缺省，不能覆盖明确的角色服饰、场景、对白和剧情。

## 数据和兼容

- 虾格预设通过 `theme_options` 声明能力。主题缺省为 `null`，无需批量迁移旧项目。
- 主线项目使用 `visual_style_theme`；PATCH 未提供该字段表示不更新，显式 `null` 表示恢复默认。改选其他预设时清除旧主题；给不支持主题的预设设置非空主题返回 400。
- `StyleService` 返回项目对应的有效配置，复制缓存预设后解析主题，避免改写共享缓存。
- 角色、分镜、场景、视频共用具体画风规则解析；`1b` 替换背景和线条极性，`2a` 单独使用高调白色科技空间和青蓝 UI，`2b` 使用彩色叙事环境，`3` 使用手绘土色规则，避免将多套冲突规则叠加。规则版本提升为 `stickman-themes-v2`。
- 风格详情缓存按项目和预设共同区分；保存主题后重新获取有效风格指令，避免显示另一项目或旧主题的参数。

## 主线任务快照

主线提交任务时捕获完整 `style_snapshot`，含主题、有效风格指令和 `rules_version`。执行时使用任务局部上下文；模型子进程通过独立环境变量继承这份非敏感渲染配置，避免修改工作进程的全局环境。后续项目主题变更不影响已捕获的任务。

没有主题快照的旧队列任务无法追溯其提交时设置，应在升级前排空或重新提交；真实模型质量仍需独立验收。

## 静态封面与生成产物

`src/novelvideo/styles/presets/stickman.png` 是用户指定的原图，供主线预览接口使用。
前端虾格调用 `/api/v1/styles/stickman/preview` 显示封面，不依赖前端静态风格图库，封面不作为模型参考图。
